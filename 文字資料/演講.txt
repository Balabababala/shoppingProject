各位好，我是張允豪，今天很高興為大家介紹我們的 C2C 電子商務平台專題。這是一個整合買家、賣家和管理員功能的購物網站，採用 React 打造響應式前端介面，Spring Boot 提供穩健的後端邏輯，搭配 MySQL 作為高效的資料庫。我們的目標是打造一個功能完善、操作直觀的電子商務平台，支援商品瀏覽、購物車管理、訂單處理、推薦系統等功能，讓用戶享受流暢的購物體驗。

系統功能介紹（3.5 分鐘）

我們的平台為不同角色設計了專屬功能：

未登錄用戶：可瀏覽首頁的推薦商品、商品分類，並進行搜尋，同時提供快速註冊和登錄入口，透過 Email 驗證確保註冊流程簡單且安全。
買家功能：買家可在首頁查看推薦商品，通過商品分類或搜尋找到心儀產品。系統記錄最近瀏覽的商品，方便回顧。購物車支援新增、修改和刪除商品；訂單管理允許查看和部分修改訂單資訊；用戶還可收藏喜愛商品、接收系統通知，並更新個人資料，如地址和電話。
賣家功能：賣家可管理自己的商品，包括上架、編輯商品資訊和查看訂單。系統也提供最近瀏覽紀錄和通知中心，幫助賣家跟進買家需求。
後台功能：管理員擁有全面的管理權限，包括：
商品與分類管理：新增、修改商品，管理分類結構，並上傳圖片與控制庫存。
評論管理：審核用戶評論，結合 Ollama 的 Qwen2 AI 模型進行自動化審核，過濾不當內容。
訂單管理：查看訂單列表與詳情，確保交易順利進行。
使用者管理：管理用戶資料、設定角色權限（如買家、賣家、管理員），並支援封鎖或解鎖帳號。
推薦與搜尋管理：設定推薦規則（如熱門商品或基於用戶行為的推薦），並追蹤用戶的搜尋和瀏覽歷史，優化推薦效果。
通知管理：發送個人化或系統通知，提升用戶互動。
技術架構與資料庫設計（2.5 分鐘）

我們的技術架構採用 React 實現動態前端，Spring Boot 處理業務邏輯，MySQL 儲存所有資料。資料庫設計包含多個核心表格：

users 與 roles：管理用戶帳號與角色權限，支援買家、賣家和管理員的區分，並記錄登錄日誌以提升安全性。
products 與 categories：支援商品和分類管理，包含價格、庫存和圖片，並使用全文索引優化搜尋效率。
orders 與 order_items：記錄訂單詳情，支援多種訂單狀態和物流追蹤。
recommended_products 與 recommend_rules：實現基於規則的商品推薦，未來可擴展至機器學習模型。
product_reviews 與 notifications：支援評論審核（包含 AI 輔助）和通知管理，提升用戶體驗。
我們在高頻查詢場景中新增複合索引，確保系統效能，並採用軟刪除機制保護資料完整性。

未來展望與總結（1 分鐘）

未來，我們計劃整合真實的物流和支付系統，例如對接順豐物流和 Stripe 支付 API，提升交易真實性。同時，我們將完善推薦系統，引入基於機器學習的個性化推薦，並優化通知和訂單物流追蹤功能。這個專題展示了我們對 C2C 電子商務平台的完整構想，從前台購物到後台管理，結合現代化技術棧，實現高效且用戶友好的體驗。感謝大家的聆聽，歡迎提問！

# 系統架構介紹稿

## 開場
大家好，今天要為大家介紹我們這個全端 Web 應用的系統架構。這是一個採用前後端分離設計的現代化應用程式。

## 整體架構概述
我們的系統主要分為三個部分：前端、後端，以及數據存儲層。讓我逐一為大家說明。

## 前端架構
前端我們選用了 React 作為主要的 UI 框架，搭配 Bootstrap 來處理響應式設計和 UI 組件。當然，基礎的 HTML、CSS、JavaScript 也是不可缺少的。React 讓我們能夠建立動態且互動性強的用戶介面。

## 後端架構
後端是我們的核心，採用 Spring Boot 生態系統。這裡包含了 Spring Boot 本身、Spring Security 負責安全控制，還有 Spring AI 來集成人工智能功能。

### 安全機制
在安全方面，我們實作了一套完整的認證授權機制。首先是 JWT Token 驗證，我們使用自定義的 JwtAuthenticationFilter，並透過 Spring Security Filter Chain 將它插入在 UsernamePasswordAuthenticationFilter 之前，這樣確保 JWT 驗證能夠優先執行。

同時，我們使用 BCrypt 來加密用戶密碼，確保即使數據庫被入侵，密碼也不會以明文方式洩露。

### 應用分層架構
我們採用標準的 MVC 架構模式：

**Controller 層**負責處理所有的 HTTP 請求和響應，定義 API 端點。特別值得一提的是，我們實作了全局異常處理機制，使用 @ControllerAdvice 和 @ExceptionHandler 來統一處理系統中的各種異常。

**Service 層**是我們的業務邏輯核心，處理所有的商業規則和流程，同時管理事務。

**Repository 層**負責數據持久化操作，透過 JPA 和 Hibernate ORM 來簡化數據庫操作。

## 數據模型設計
在數據處理上，我們定義了清楚的數據模型：
- Entity 用於數據庫實體映射
- DTO 作為數據傳輸對象
- DAO 處理數據訪問邏輯

## 數據庫層
數據存儲我們選用 MySQL 作為主要數據庫。值得一提的是，Spring Boot 預設使用 HikariCP 作為連接池，這是一個高性能的數據庫連接池，能夠有效管理數據庫連接，提升系統性能。

JPA 和 Hibernate 作為我們的 ORM 框架，大大簡化了數據庫操作的複雜度。

## 數據流向
整個系統的數據流向是這樣的：React 前端發送請求，經過 JWT Filter 驗證，到達 Controller，再通過 Service 處理業務邏輯，最後透過 Repository 和 JPA/Hibernate 與 MySQL 數據庫交互。這是一個完整的雙向數據流。

## 開發工具整合
我們還整合了 Ollama 作為本地 AI 模型運行環境，這讓我們能夠在本地開發和測試 AI 功能，無需依賴外部 API。

## 架構優勢
這個架構設計有幾個主要優勢：

1. **前後端分離**：讓前端和後端團隊可以獨立開發和部署
2. **分層清晰**：每一層都有明確的職責，易於維護
3. **安全完善**：JWT 加上 Spring Security 提供雙重安全保護
4. **性能優化**：HikariCP 連接池確保數據庫操作的高效性
5. **擴展性好**：模組化設計讓未來的功能擴展變得容易

## 結語
這是一個成熟的企業級應用架構，適合中小型到大型的 Web 應用開發。整個設計考慮了安全性、性能、可維護性和擴展性，是一個相當完整的解決方案。
